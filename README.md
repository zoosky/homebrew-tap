# Homebrew tap for zoosky's tools

Install yqr, the YAML query and editing tool with a fidelity guarantee:

```sh
brew install zoosky/tap/yqr
```

The formula here is generated and pushed by yqr's release pipeline
(dist, from the release's prebuilt binaries). Don't edit it by hand:
the next release overwrites it. Issues belong on the tool's own
repository: https://github.com/zoosky/yqr
